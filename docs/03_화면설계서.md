# 03. 화면설계서
## 일본 골프 여행 가이드

# 1. 기본 UI 원칙

대상 고객:

- 여행 중 스마트폰 사용
- 긴 설명보다 빠른 정보 탐색 선호
- 한 손 조작

따라서:

- 큰 버튼
- 명확한 텍스트
- 깊은 메뉴 금지
- 한 화면에 너무 많은 정보 금지
- 2~3번 터치 안에 원하는 답 확인

## 배경 이미지

모든 고객 페이지에는 지역별 반응형 배경 이미지가 적용된다.

- 메인: main-background
- 도스: sub-background-1
- 벳푸: sub-background-2

화면 크기에 따라 mobile/tablet/desktop WebP가 로드된다.

배경 위에는 `rgba(255, 255, 255, 0.78)` 반투명 흰색 overlay가 적용되어 텍스트 가독성을 보장한다.

# 7. FAQ 화면

```text
환전

[ 질문 검색 ]

Q. 일본에서 현금이 꼭 필요한가요?
▼

Q. 한국 카드로 ATM 출금 가능한가요?
▼

Q. ATM 수수료는 얼마인가요?
▼
```

Accordion 사용.

한 번에 하나 또는 여러 개 펼치기 허용.

# 11. 질문 목록

```text
도스 > 골프장

[ + 질문 추가 ]

[질문 검색____________]

┌─────────────────────────┐
│ 반바지 착용 가능한가요? │
│ 카오 골프장             │
│ 노출중                   │
│                         │
│ [↑] [↓] [수정] [숨김]   │
└─────────────────────────┘
```

절대 표시하지 말 것:

- id
- DOS
- GOLF
- related_id
- sort=1

# 13. 관리자 수정

기존 값 preload.

저장 전 변경사항이 있으면 뒤로가기 시:

```text
저장하지 않은 내용이 있습니다.
나가시겠습니까?
```

---

# 14. 관리자 정렬

숫자 입력 금지.

사용:

```text
↑ 위로
↓ 아래로
```

MVP에서는 드래그보다 위/아래 버튼이 더 단순하고 안정적.

---

# 15. 관리자 용어

영문 코드 대신 항상 한국어:

| 내부 | 관리자 표시 |
|---|---|
| DOS | 도스 |
| BEPPU | 벳푸 |
| ALL | 공통 |
| GOLF | 골프장 |
| HOTEL | 호텔 |
| ONSEN | 온천 |
| DRIVER | 차량 |
| RESTAURANT | 맛집 |
| GENERAL | 기타 |
| REFUND | 환불 |
| MONEY | 환전 |
| EXTRA_PAYMENT | 추가결제 |
| TRUE | 노출중 |
| FALSE | 숨김 |

# 16. Empty State

질문이 없을 때:

```text
등록된 질문이 없습니다.

[ + 첫 질문 추가 ]
```

---

# 17. 오류

```text
저장 중 문제가 발생했습니다.
내용은 유지되어 있습니다.
다시 저장해주세요.
```

입력값을 날리지 않는다.
