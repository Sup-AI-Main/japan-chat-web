# 05. 디자인 시스템 가이드
## 일본 골프 여행 가이드

# 1. 디자인 목표

이 웹앱은 화려함보다:

- 빠름
- 읽기 쉬움
- 직관성
- 여행 중 즉시 사용

이 우선이다.

---

# 2. 스타일 방향

키워드:

```text
Clean
Light
Travel
Japanese
Golf
Simple
Mobile First
```

과도한 일본풍 장식 금지.

---

# 3. 색상

권장 기본:

```css
--bg: #F7F8FA;
--surface: #FFFFFF;
--text: #111827;
--muted: #6B7280;
--border: #E5E7EB;
--primary: #1F7A5A;
--primary-soft: #EAF5F0;
--danger: #DC2626;
--warning: #D97706;
--success: #15803D;
```

골프 특성을 고려해 Primary는 차분한 그린 계열.

색은 의미 전달 용도 위주.

---

# 4. 지역별 색상

도스/벳푸를 완전히 다른 테마로 만들지 않는다.

필요하면 작은 accent만 허용.

예:

```text
도스 accent: Green
벳푸 accent: Warm Blue
```

전체 디자인 시스템은 동일.

---

# 5. Typography

OS 기본 시스템 폰트 우선.

```css

-apple-system,
BlinkMacSystemFont,
"Segoe UI",
"Apple SD Gothic Neo",
"Noto Sans KR",
sans-serif;
```

외부 웹폰트를 굳이 로딩하지 않는다.

속도 우선.

# 29. 이모지 + 카테고리 색상 시스템

## 지역 이모지

지역명 앞에 일본 느낌 이모지를 배치한다.

```text
💮 도스
🎋 벳푸
🌏 공통
```

구현: `src/lib/display.ts`의 `getAreaEmoji(code)`

## 카테고리 이모지

모든 카테고리명 앞에 해당 카테고리와 어울리는 이모지를 표시한다.

```text
⛳ 골프장
🏨 호텔
🍜 맛집
♨️ 온천
🚗 차량
📌 기타
💰 환불
💱 환전
💳 추가결제
```

구현: `src/lib/display.ts`의 `getCategoryEmoji(code)`

알려지지 않은 카테고리는 기본값 `📌`를 사용한다.

## 카테고리별 색상

각 카테고리는 고유 색상을 가진다. 카드 배경, border, 텍스트에 적용한다.

```text
골프장(GOLF): Green (#2d7a3a, bg #e8f5e9, border #81c784)
호텔(HOTEL): Blue (#1565c0, bg #e3f2fd, border #64b5f6)
맛집(RESTAURANT): Red (#c62828, bg #fbe9e7, border #ef9a9a)
온천(ONSEN): Purple (#7b1fa2, bg #f3e5f5, border #ce93d8)
차량(DRIVER): Sky Blue (#0277bd, bg #e1f5fe, border #4fc3f7)
기타(GENERAL): Gray (#546e7a, bg #eceff1, border #90a4ae)
환불(REFUND): Orange (#e65100, bg #fff3e0, border #ffb74d)
환전(MONEY): Green (#2e7d32, bg #e8f5e9, border #a5d6a7)
추가결제(EXTRA_PAYMENT): Indigo (#4527a0, bg #ede7f6, border #b39ddb)
```

알려지지 않은 카테고리는 기본값 Gray를 사용한다.

## 적용 위치

- 고객 지역 홈: 카테고리 카드 배경+border+텍스트 색상
- 고객 FAQ 페이지: 제목 색상, accordion border
- 관리자 카테고리 선택: 카드 배경+border+텍스트 색상
- 관리자 FAQ 목록: 카드 border 색상
- 모든 페이지: 지역명 앞 이모지, 카테고리명 앞 이모지

## 구현

`src/lib/display.ts`에서 모든 색상/이모지를 관리한다.

```ts
getAreaEmoji(code)        // 지역 이모지
getCategoryEmoji(code)    // 카테고리 이모지
getCategoryColor(code)    // 텍스트 색상
getCategoryBg(code)       // 배경 색상
getCategoryBorder(code)   // 테두리 색상
getCategoryConfig(code)   // 전체 설정
```

# 31. 반응형 배경 이미지

## 개요

모든 고객 페이지에는 지역별 반응형 배경 이미지가 적용된다. PNG 원본을 WebP로 변환하여 사용한다.

## 파일 구조

```text
public/background/
├─ main-background-mobile.webp     (768×432)
├─ main-background-tablet.webp     (1280×720)
├─ main-background-desktop.webp    (1920×1080)
├─ sub-background-1-mobile.webp    (768×432)
├─ sub-background-1-tablet.webp    (1280×720)
├─ sub-background-1-desktop.webp   (1920×1080)
├─ sub-background-2-mobile.webp    (768×432)
├─ sub-background-2-tablet.webp    (1280×720)
└─ sub-background-2-desktop.webp   (1920×1080)
```

## 페이지 매핑

| 페이지 | CSS 클래스 | 배경 파일 |
|---|---|---|
| 메인 (`/`) | `bg-main` | main-background-* |
| 도스 (`/dos` + 하위) | `bg-dos` | sub-background-1-* |
| 벳푸 (`/beppu` + 하위) | `bg-beppu` | sub-background-2-* |

## 반응형 로딩

CSS media query로 화면 크기에 따라 하나의 WebP만 로드한다. Mobile First.

```css
/* Mobile (기본) */
.bg-main { background-image: url("/background/main-background-mobile.webp"); }

/* Tablet: ≥768px */
@media (min-width: 768px) {
  .bg-main { background-image: url("/background/main-background-tablet.webp"); }
}

/* Desktop: ≥1280px */
@media (min-width: 1280px) {
  .bg-main { background-image: url("/background/main-background-desktop.webp"); }
}
```

## Overlay

배경 위에 반투명 흰색 overlay를 적용한다.

```css
.page-bg::before {
  content: "";
  position: fixed;
  inset: 0;
  background: rgba(255, 255, 255, 0.78);
  z-index: 0;
  pointer-events: none;
}
```

조절 범위: `0.75 ~ 0.85`

목적:

- 배경 그림은 은은하게 보이게
- 질문/카테고리/텍스트 가독성은 높게 유지

## 구현 파일

- `src/app/globals.css`: `.page-bg`, `.bg-main`, `.bg-dos`, `.bg-beppu` 클래스
- `src/app/[area]/layout.tsx`: 지역별 배경 자동 적용 (모든 하위 페이지 상속)
- `src/app/page.tsx`: 메인 페이지 배경 적용

## 원본 보관

PNG 원본은 `background/` 폴더에 보관한다. 웹에서는 WebP만 사용한다. SVG는 사용하지 않는다.

## 용량 목표

| 버전 | 목표 용량 |
|---|---|
| mobile | 100~250KB 이하 |
| tablet | 150~350KB 이하 |
| desktop | 200~500KB 이하 |
