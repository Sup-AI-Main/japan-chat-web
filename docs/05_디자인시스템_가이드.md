# 05. 디자인 시스템 가이드
## 일본 골프 여행 가이드

# 1. 디자인 목표

이 웹앱은 화려함보다:

- 빠름
- 읽기 쉬움
- 직관성
- 여행 중 즉시 사용

이 우선이다.

---

# 2. 스타일 방향

키워드:

```text
Clean
Light
Travel
Japanese
Golf
Simple
Mobile First
```

과도한 일본풍 장식 금지.

---

# 3. 색상

권장 기본:

```css
--bg: #F7F8FA;
--surface: #FFFFFF;
--text: #111827;
--muted: #6B7280;
--border: #E5E7EB;
--primary: #1F7A5A;
--primary-soft: #EAF5F0;
--danger: #DC2626;
--warning: #D97706;
--success: #15803D;
```

골프 특성을 고려해 Primary는 차분한 그린 계열.

색은 의미 전달 용도 위주.

---

# 4. 지역별 색상

도스/벳푸를 완전히 다른 테마로 만들지 않는다.

필요하면 작은 accent만 허용.

예:

```text
도스 accent: Green
벳푸 accent: Warm Blue
```

전체 디자인 시스템은 동일.

---

# 5. Typography

OS 기본 시스템 폰트 우선.

```css
font-family:
-apple-system,
BlinkMacSystemFont,
"Segoe UI",
"Apple SD Gothic Neo",
"Noto Sans KR",
sans-serif;
```

외부 웹폰트를 굳이 로딩하지 않는다.

속도 우선.

---

# 6. Font Size

```text
Page Title: 24~28
Section Title: 18~20
Card Title: 16~18
Body: 15~16
Meta: 13~14
```

모바일에서 14px 미만 본문 사용 금지.

---

# 7. Spacing

기준 단위:

4px.

주요 간격:

```text
4
8
12
16
20
24
32
```

---

# 8. Radius

```text
Small: 8px
Card: 12px
Large Card: 16px
Button: 10~12px
```

지나치게 둥근 pill UI 남용 금지.

---

# 9. Shadow

거의 사용하지 않는다.

Card:

```css
box-shadow: 0 1px 2px rgba(0,0,0,.05);
```

Border 중심으로 구성.

---

# 10. 버튼

Primary:

- 높이 최소 44px
- 명확한 label
- icon-only 금지

Secondary:

- 흰 배경
- border

Danger:

- 삭제가 아니라 숨김에 사용하지 않음
- 실제 위험 동작에만 사용

---

# 11. 카드

고객용 카드:

```text
제목
짧은 설명
보조정보
CTA
```

한 카드 안에 너무 많은 정보 금지.

---

# 12. FAQ Accordion

질문:

- 굵게
- 클릭 영역 전체
- chevron

답변:

- line-height 1.6
- 충분한 padding

---

# 13. 관리자 UI

관리자는 컴퓨터를 잘 모르는 사람을 기준으로 설계한다.

원칙:

- 영어 코드 금지
- ID 금지
- 기술 용어 금지
- 필수 입력만 표시
- 설명을 필드 바로 아래 제공

---

# 14. 관리자 Form

Label 예:

```text
질문
고객에게 보일 질문을 입력하세요.

답변
고객에게 안내할 내용을 쉽게 적어주세요.
```

금지:

```text
related_id
category code
sort index
```

---

# 15. 관리자 Select

예:

```text
질문 종류
[ 골프장 ▼ ]
```

코드값은 내부에서 처리.

---

# 16. 관리자 Scope

Radio button:

```text
이 질문은 어디에 보여줄까요?

(●) 도스 전체
( ) 특정 골프장
```

기술적인 "AREA / SPECIFIC" 표현 금지.

---

# 17. 노출 여부

```text
고객 화면에 표시
[ ON ]
```

TRUE/FALSE 금지.

---

# 18. 정렬

```text
[↑ 위로]
[↓ 아래로]
```

`정렬순서 1` 같은 숫자 입력 UI 금지.

---

# 19. 관리자 저장 버튼

화면 하단 고정 가능.

```text
[취소] [저장]
```

저장 중:

```text
저장 중...
```

중복 클릭 방지.

---

# 20. 상태

노출중:

```text
노출중
```

숨김:

```text
숨김
```

정보 검증:

```text
공식 확인
확인 필요
```

관리자에게 색만으로 상태를 전달하지 않는다.

---

# 21. 테이블 대신 카드

모바일 관리자에서는 table 금지.

카드 목록 사용.

Desktop에서도 동일 카드 구조를 유지해 관리 난이도 최소화.

---

# 22. Loading

Skeleton 최소화.

텍스트 중심 페이지는 단순:

```text
불러오는 중...
```

도 가능.

---

# 23. Empty State

친절하고 짧게:

```text
등록된 질문이 없습니다.
[첫 질문 추가]
```

---

# 24. 접근성

- contrast 준수
- button 44px 이상
- form label 연결
- keyboard focus 표시
- accordion aria-expanded
- 색만으로 상태 구분 금지

---

# 25. 애니메이션

필요 최소.

```text
150~200ms
```

페이지 전환 애니메이션 불필요.

Parallax, heavy motion 금지.

---

# 26. 반응형

기준:

```text
Mobile: 기본
Tablet: 768+
Desktop: 1024+
```

모바일 먼저 설계.

---

# 27. 최대 폭

고객 콘텐츠:

```css
max-width: 720px;
```

관리자:

```css
max-width: 900px;
```

가운데 정렬.

---

# 28. Icon

가능하면:

- lucide-react 정도
- 필요한 아이콘만 import

아이콘 없는 텍스트 버튼도 허용.

---

# 29. 디자인 금지사항

- Glassmorphism
- 복잡한 gradient
- 자동재생 animation
- 대형 hero video
- 불필요 carousel
- modal 남용
- 작은 글씨
- icon-only navigation
