# 06 - 디자인 시스템 가이드라인

## Admin Modal / Dialog 공통 규칙

### 공통 컴포넌트

| 컴포넌트 | 경로 | 용도 |
|----------|------|------|
| `ModalShell` | `src/components/inline-cms/ModalShell.tsx` | 모든 관리자 Modal의 최상위 base 컴포넌트 |
| `EditModalShell` | `src/components/inline-cms/EditModalShell.tsx` | ModalShell + 저장/취소 footer가 포함된 편집 전용 컴포넌트 |

### 구조

```text
ModalShell
 ├─ overlay (click으로 닫히지 않음)
 ├─ sticky header
 │   ├─ title
 │   └─ X close button (aria-label="닫기")
 ├─ scrollable content
 └─ sticky footer (optional, via footer prop)

EditModalShell
 └─ ModalShell
     ├─ form children
     ├─ cancel button (footer)
     └─ save button (footer)
```

### 공통 UX 규칙

| 규칙 | 설명 |
|------|------|
| 공통 shell 사용 | 관리자 create/edit modal은 반드시 `ModalShell` 또는 `EditModalShell` 사용 |
| 전용 layout 금지 | 특정 Entity 전용 modal layout을 개별 생성하지 말 것 |
| outside click 차단 | overlay 클릭으로 절대 닫히지 않음 |
| Escape 차단 | 기본적으로 Escape로 임의 닫힘 방지 |
| 허용되는 닫기 | X 버튼 / 취소 버튼 / 저장 성공 후 정상 close |
| Desktop/Tablet | 넓은 modal, 기본 2열 form layout |
| Mobile | viewport 기반 responsive, 1열 |
| textarea/설명/긴 field | `md:col-span-2`로 full-width 허용 |
| header/footer | sticky (flex-shrink-0) |
| content | scroll만 허용 (overflow-y-auto) |
| horizontal overflow | 금지 |

### 폭 기준

| Modal 유형 | Desktop max-width | Mobile |
|-----------|-------------------|--------|
| Edit modal (Entity CRUD) | `1050px` | `calc(100vw - 24px)` |
| 기타 modal/dialog | `900px` | `calc(100vw - 24px)` |
| Confirm/삭제 확인 | `420px` | `calc(100vw - 24px)` |

### 높이 기준

| 구간 | max-height |
|------|-----------|
| Desktop | `calc(100vh - 40px)` |
| Mobile | `calc(100dvh - 24px)` |

### Form Grid 규칙

```tsx
// Edit form sections
<div className="grid grid-cols-1 md:grid-cols-2 gap-x-5 gap-y-4">
  <InputField label="필드1" ... />
  <InputField label="필드2" ... />
  <InputField className="md:col-span-2" label="긴 필드" ... />
</div>
```

- `< 768px`: 1열 (`grid-cols-1`)
- `>= 768px`: 2열 (`md:grid-cols-2`)
- textarea, 설명 등 긴 필드: `md:col-span-2`

### ModalShell 사용 예시

```tsx
import { ModalShell } from "@/components/inline-cms/ModalShell";

<ModalShell
  open={open}
  title="제목"
  onClose={handleClose}
  error={error}
  footer={
    <>
      <button onClick={onClose}>취소</button>
      <button onClick={onSave}>저장</button>
    </>
  }
>
  {/* form content */}
</ModalShell>
```

### EditModalShell 사용 예시

```tsx
import { EditModalShell } from "@/components/inline-cms/EditModalShell";

<EditModalShell
  open={open}
  title="식당 수정"
  onClose={onClose}
  onSave={handleSave}
  saving={saving}
  error={error}
>
  <div className="grid grid-cols-1 md:grid-cols-2 gap-x-5 gap-y-4">
    <InputField label="이름" ... />
    <InputField label="전화번호" ... />
  </div>
</EditModalShell>
```

### 향후 새 Entity / Category 추가 시

새로운 Entity CRUD 화면이나 Admin 편집 화면을 만들 때는 반드시 이 공통 modal system을 사용해야 합니다.

- `ModalShell` 또는 `EditModalShell`을 import하여 사용
- 개별적으로 overlay, X 버튼, sticky header/footer를 구현하지 말 것
- outside click close를 추가하지 말 것

### 예외

- Confirm modal 같이 작은 UI는 데이터 입력용 2열 layout을 강제로 적용하지 않아도 됩니다.
- `maxWidth` prop으로 적절한 폭을 지정할 수 있습니다.
